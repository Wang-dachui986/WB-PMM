# Token 统计

左侧「Token 统计」可查看日、周、月、年度用量。日期选择所需周期，周从星期一开始。当前统一按 UTC 统计，同一历史在不同电脑时区中保持一致。

- 方块热力图：日视图每格一小时，其余每格一天；颜色越深，用量越多。虚线提示存在未返回用量的请求。
- 扇形图：所选周期各模型的 Token 占比。
- 柱状图 / 曲线图：所选周期的时间趋势。
- 模型筛选和明细表：查看每个模型的输入、输出、合计、占比及用量返回次数。点击「刷新统计」获取最新数据，不调用模型、不消耗积分。

## 统计口径

只累计网关请求结束时收到的上游 usage；总 Token 为已观测输入与输出之和。缓存属于输入，不重复累加。未返回 usage 的请求标为未知，不估算为真实零消耗；usage 内部分字段缺失时，仅累计返回值。失败或中断的请求也可能产生用量，若网关收到 usage，则仍计入。三个兼容协议沿用同一请求统计入口，避免重复计数。

历史从升级后的首次启动开始，无法补回之前未保存的数据。历史独立于「请求统计」中的本次运行统计，重启和重置本次统计不会主动清空历史。

## 保存方式

与 gateway state 文件同目录的 `token-history.json`，只保存时间、模型名及汇总计数，不包含账号、密钥、提示词和回答。

有变更才写入，最多每分钟一次，并在网关正常退出时保存。崩溃、断电、强制结束或关闭超时可能丢失最近一分钟记录。保存失败会在页面提示；历史文件损坏时保留原文件，当前记录仅存内存，不覆盖损坏文件。

保留最近 400 天，最多 200000 个「模型 × 小时」记录。达到容量时页面提示部分新记录未计入。超过保留期的历史不在当前统计范围内。

## 验证范围

Go 测试覆盖持久化恢复、缺失 usage、时间范围、保留期、无变化不写盘、当前统计重置隔离、桌面会话代理和局域网不可读取历史；前端检查覆盖周界、闰年、模型筛选及汇总。图表使用模拟数据做页面检查。未进行收费模型请求，也未完成 Windows 实机验收。
