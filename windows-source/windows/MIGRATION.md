# Windows 迁移与统一验收

## 边界

- 目标：Windows 10 22H2 / Windows 11，Intel/AMD x64；功能对齐冻结的 macOS 1.0.3。
- 交付方式：Setup.exe，首次安装可选目录，默认 `%LOCALAPPDATA%\Programs\WB-PMM`，升级沿用所选位置，无免安装版本。
- 数据目录：`%LOCALAPPDATA%\WB-PMM`。升级、卸载不移除账号、配置或偏好。
- 实现：现有 Go 网关 + Go/React 管理面板，Windows 原生层使用 .NET 10 WinForms/WebView2。
- 按用户要求，所有迁移功能处理完成后，再统一进入 Windows 实机验收。本表将本地开发检查和实机验收分开。

## 统一 Windows 验收顺序

每台机器单独记录 OS 版本、x64、是否已装 WebView2、安装包 SHA-256、结果与复现步骤。先用合成账号/数据；真实授权与模型调用安排在最后，收费请求需另定次数和积分范围。

1. 干净安装：非管理员用户、中文/空格用户名、WebView2 已存在和缺失各一轮。目录页选择默认/自定义磁盘/中文空格路径；验证不可写目录被拒绝，开始菜单图标正常。
2. 基础自动检查：在 Windows 源码目录执行 `windows/verify.ps1`，要求 Foundation Windows ACL/Job 与 Go Windows 专项全部通过。
3. 生命周期：连续打开两次仅一实例；关窗保留 API；托盘再打开；正常退出后无孤儿 helper；端口冲突不影响占用进程；睡眠/唤醒后状态恢复。
4. 引导与操作：最小窗口、缩放 100%/150%/200%、跳过/重看引导、主题、鼠标/触控板滚动、状态颜色与复制按钮。
5. 账号与事务：取消 OAuth、过期、保存失败重试、凭证导入重复 UID、100 个合成账户上限、禁用/删除确认、维护前后恢复、配置冲突/失败回滚。真实账号只按用户批准范围添加。
6. 网络：本机三协议、API 密钥错误拒绝；同 Wi-Fi 第二台设备访问允许的 API；远程管理/健康接口仍拒绝；关闭 LAN 后远程不可达；防火墙仅私有网络放行。
7. 功能：余额单/批/全量、部分失败、签到计划状态、模型参数与流式取消、统计日志诊断。真实上游不因自动测试重复扣费。
8. 安装升级：旧版运行且有数据时安装新版，正常退出后覆盖；任务栏旧快捷方式仍打开所选位置的新版本；账号/偏好/开机项保留。退出失败应中止，不强制抹掉在途操作。
9. 卸载/重装：卸载程序文件和快捷方式，保留用户数据和其它无关文件；重装后数据可读。首次使用和旧数据升级都通过才结束验收。

只有两套目标系统的实机记录完成后，才能把 Windows 版标记为已验收发布。现有 Mac 签名不等于 Windows Authenticode，测试安装包的签名状态应如实记录。
