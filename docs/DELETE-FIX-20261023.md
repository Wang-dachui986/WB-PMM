# 取消删除恢复与批量删除（2026-10-23）

## 根因

原生账号维护确认被取消时 begin.ready 拒绝，此时没有租约可供 end。原 finishMaintenance 等待 end 失败后保留本地维护引用和 deleting=true，ConfirmDialog 的取消/关闭按钮又因 busy 被禁用，形成无法操作的遮罩。

## 修改

- 结束维护失败时通过原有 cancel_pending 确认清理；收到清理确认后才释放页面维护引用。若清理仍失败，关闭删除对话框并保留维护提示，用户可重试取消维护。
- 新增批量删除，仅作用于明确选中的1–100个账号，确认框列出全部昵称和完整UID。没有选择时禁用，禁止默认删除全部。
- 沿用每账号删除通道，在一个绑定所选UID集合的原生维护许可内逐个删除；Mac/Windows原生桥、网页API和Go许可层均检查成员身份。刷新/积分仍限20个，登录/导入限制不变。
- 成功删除后清除该账号选择和本地备注；失败或返回不确定时立即停止，不重试，保留其余选择。离开页面沿用撤销和排空流程。

## 验证

使用合成账号的真实浏览器回归覆盖网页取消不发送删除、原生取消等待清理后恢复、取消后重试、部分失败停止、单个账号取消、100账号单许可顺序删除与未选UID拒绝。原账号页迟到响应/取消/导入/登录回归通过。Go临时凭证目录验证100上限、未选账号保护与跨动作拒绝；原生隔离测试与构建报告见本次产物。

没有删除或修改用户现有凭证。Windows安装与托盘等完整实机验收未执行。
